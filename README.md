# Cloudflare D1 Java Client

## Installation

### Using JitPack

Add the JitPack repository to your build file:

```gradle
repositories {
    maven { url 'https://jitpack.io' }
}
```

Add the dependency:

```gradle
dependencies {
    implementation 'com.github.juanegiraldoa:cloudflare-d1-client:{RELEASE_TAG}'
}
```

replace `RELEASE_TAG` with a specific release tag from [here](https://github.com/juanegiraldoa/cloudflare-d1-client/releases)
